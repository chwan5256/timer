# ⏱ 교사용 타이머

**수업·연수를 위한 올인원 도구** — 타이머 · 스톱워치 · 시계 · 알람(교시 벨) · 뽑기 · 소음 측정 · 캡처 고정

## ✨ 7개 모드

| 모드 | 내용 |
|------|------|
| ⏱ 타이머 | 단일/연속 시퀀스(설명→토의→발표), 종료 메시지, ±시간, 초과시간 |
| ⏲ 스톱워치 | 1/100초, 랩 기록 |
| 🕐 시계 | 대형 시계 + 세계 도시 동시 표시 |
| ⏰ 알람 | 요일 반복, 스누즈, **교시 시간표 자동 벨** |
| 🎲 뽑기 | 발표자 뽑기(중복 제외), 모둠 편성(복사·이미지·엑셀), 엑셀 명단 붙여넣기 |
| 🎤 소음 측정 | 신호등(🟢🟡🔴) 레벨, 경고 기준·경고음 |
| 📌 **캡처 고정** | 영역 드래그 → **테두리 없는 순수 이미지 창**으로 모든 프로그램 위에 고정, **여러 장 동시 가능** |

공통: 📌 공지 보드(Wi-Fi·교안 링크 상시 표시) · 🗔 미니 창 · 📍 항상 위 · 🔔 주의벨 · 다크/라이트

### 📌 캡처 고정 — 이 도구의 시그니처 기능
저장·편집은 윈도우 캡처 도구(Win+Shift+S)의 몫입니다. 이 기능은 **수업 화면의 학습목표·그림·문제를 잘라 화면 위에 "붙여두는" 것** 하나에 집중합니다. PPT를 넘겨도, 판서를 해도 고정 창은 그대로 남습니다.
고정 창 조작: **이동** 드래그 · **크기** 마우스 휠 · **닫기** 우클릭 또는 ESC

## ❓ 자주 묻는 질문

**Q. 화면에 보이는 `127.0.0.1:47614`는 뭔가요? 위험한가요?**
`127.0.0.1`은 "**내 컴퓨터 자신**"을 가리키는 내부 전용 주소(루프백)이고, `47614`는 이 프로그램이 쓰는 문 번호(포트)입니다. 프로그램의 화면부(브라우저 창)와 기능부(exe)가 **내 컴퓨터 안에서만** 대화하는 통로이며, 인터넷 주소가 아닙니다. 같은 컴퓨터 밖에서는 접근 자체가 불가능하고, 실행마다 새로 만들어지는 비밀 토큰 없이는 어떤 기능도 호출할 수 없습니다. → 개인정보 위험 없음.

**Q. 데이터가 어디에 저장되나요?**
전부 내 컴퓨터에만: 명단·공지·설정은 브라우저 저장소, 캡처는 화면 표시 전용(프로그램이 파일을 쓰지 않음).

## 🛡 보안
- **외부 통신 0건** — 전송 코드가 존재하지 않음 (소스로 검증 가능)
- **디스크 기록 없음** — 프로그램이 어떤 파일도 저장하지 않음
- **로컬 API 토큰 보호** + Host/Origin 검증 — 외부 웹사이트의 localhost 악용 차단
- **캡처는 사용자의 버튼 조작으로만** — 자동/백그라운드 캡처 없음
- **개인정보 미수집** · **소스 전체 공개** · 상세: [SECURITY_AUDIT.md](SECURITY_AUDIT.md)

## 📄 면책 조항
교육 목적 무료 비상업용 도구로, 보증 없이 "있는 그대로(AS-IS)" 제공됩니다. 사용 결과(캡처물 활용 등)의 책임은 사용자에게 있으며, 화면에 학생 개인정보가 포함될 경우 관련 규정을 준수해 주세요. 원본 그대로 공유해 주시고, 의견은 chwan5256@sen.go.kr 로 보내주세요.
