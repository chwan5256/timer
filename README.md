# 교사용 타이머 v6

## 새 기능 (v6)

### 🗔 미니 창 — "둘 다" 통합 창 추가
- 🗔 메뉴에 **⏱＋📌 둘 다 (통합 창)** 옵션 추가
- 위쪽 = 타이머(클릭으로 시작/멈춤), 아래쪽 = 공지 보드가 한 창에!
- 브라우저 규격상 떠 있는 미니 창은 1개라서, 두 정보를 한 창에 합치는 방식으로 해결
- 본 화면에서 공지를 수정하면 실시간 반영

### 🎲 명단 입력 대폭 개선
- **엑셀/구글시트에서 범위를 그대로 복사 → 붙여넣기 끝!**
  - 탭·줄바꿈 혼합(범위 복사) 자동 인식
  - "이름·성명·번호·학번" 등 헤더 자동 제거
  - 번호 열이 섞여 있으면 숫자만 자동 제거 (번호만 있는 명단은 유지)
- 붙여넣는 순간 **자동 적용** (버튼 클릭 불필요)

### 👥 모둠 편성 결과 내보내기
- 📋 **복사**: "모둠 1 (4명): …" 텍스트로 클립보드 복사
- 🖼 **이미지 저장**: 카드형 PNG (학급 게시·단톡 공유용, 날짜 포함)
- 📊 **엑셀(CSV) 저장**: 모둠/이름 2열, 한글 깨짐 방지(BOM) — 엑셀 더블클릭으로 열림

### 🏫 교시 시간표 자동 벨 (알람 탭)
- 1교시 시작시각 + 수업분 + 쉬는분 + 교시 수 → **자동 생성** (개별 수정·추가 가능)
- 각 교시 **시작/종료 시각**에 차임 + 전체화면 안내 배너
- 마스터 스위치로 켜기/끄기, 시간표는 자동 저장

### 🎤 소음 측정기 (6번째 모드, 단축키 6)
- **원리**: 컴퓨터 마이크로 소리 파형을 받아 진폭(RMS)을 계산 → 상대 레벨(0~100)로 표시
- 신호등 표시: 🟢 조용 → 🟡 소란 → 🔴 시끄러움
- **경고 기준 슬라이더** + 기준 초과 1.5초 지속 시 화면 경고 + 경고음(5초 쿨다운, 끌 수 있음)
- 이번 시간 최고치 기록
- 처음 시작 시 마이크 권한 허용 1회 필요 (절대 dB 계측기가 아닌 상대값)

## 사용법
1. `교사용타이머.exe` 더블클릭 (SmartScreen 시 "추가 정보 → 실행")
2. GitHub Pages: `index.html`만 저장소에 업로드 → Settings → Pages → main /(root)
- 기존 설정·프리셋·명단·알람 모두 유지 (동일 포트 47614)
