# 업무용 타이머 v3 — 설치 및 배포 가이드

## 📦 파일 구성
| 파일 | 용도 |
|------|------|
| `업무용타이머.exe` | **윈도우 실행파일** — 더블클릭 실행, 설치·인터넷 불필요 |
| `index.html` | 프로그램 본체 (GitHub Pages 배포용 / .bat 예비 실행용) |
| `run_timer.bat` | 예비 실행기 (index.html과 같은 폴더에서 더블클릭) |

## 1️⃣ 윈도우에서 사용
1. `업무용타이머.exe` 더블클릭 → 독립 앱 창 실행
2. SmartScreen 파란 창이 뜨면 **"추가 정보 → 실행"** 1회
3. 작업표시줄 아이콘 우클릭 → **작업 표시줄에 고정** 추천
- 모든 설정(프리셋·시퀀스·공지·알람·도시)은 자동 저장·유지 (127.0.0.1:47614 고정 포트)
- v2를 쓰고 있었다면 포트가 달라 설정이 새로 시작됨 (충돌 방지 목적)

## 2️⃣ GitHub Pages 배포 (요약)
1. github.com → New repository (`work-timer`, Public)
2. "uploading an existing file" → `index.html` 업로드 → Commit
3. Settings → Pages → Source: Deploy from a branch → **main / (root)** → Save
4. 1~2분 후 `https://<아이디>.github.io/work-timer/` 완성
- 수정 시 index.html 다시 업로드하면 자동 반영

## 3️⃣ v3 새 기능
- **앱 스위치**: 타이머 | 스톱워치 | 시계 | 알람 (기본: 타이머, 단축키 1~4)
- **타이머**: 기존 전 기능 + **종료 메시지**(완료 시 전체화면으로 문구 표시, 단일/연속 각각 설정)
- **📌 공지 보드**: 헤더 드래그로 **위치 이동**, 우하단 모서리 드래그로 **크기 조절** — 위치·크기 자동 저장
- **스톱워치**: 1/100초 표시, 랩 기록(최고=청록/최저=빨강 자동 표시), Space/L/R 단축키
- **시계**: 대형 현재 시각+날짜, **세계 도시 카드 동시 표시**(20개 도시 프리셋, 시차 표시, 서머타임 자동 반영)
- **알람**: 시각+라벨+**요일 반복**, ON/OFF 토글, 1회성 알람 자동 OFF, **빠른 알람**(5분·10분·…·1시간 후), 울릴 때 **5분 스누즈**

## ⌨ 단축키
`Space` 시작/멈춤(타이머·스톱워치) · `L` 랩 · `R` 초기화 · `F` 전체화면 · `↑↓` ±30초 · `N` 공지 · `B` 벨 · `S` 시간설정 · `1~4` 모드 전환
